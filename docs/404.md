# 404 — Pagina niet gevonden

De pagina die je zoekt bestaat niet (meer), of de link is verouderd.

## Wat je nu kunt doen

- Ga naar de [startpagina](index.md)
- Gebruik de zoekfunctie (rechtsboven)

## Veelvoorkomende oorzaken

- Een pagina is verplaatst of hernoemd bij een nieuwe versie.
- Je hebt een oude bookmark of een link uit een e-mail gebruikt.
- De URL is handmatig aangepast.

Als je denkt dat dit een fout is: meld het via GitHub Issues.
